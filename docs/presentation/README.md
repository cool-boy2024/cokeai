# CokeAI 项目介绍（演示文件）

给接手伙伴看的 16 页项目全景，内容和 `docs/HANDOFF.md` 对齐。同一份内容有三种打开方式：

| 文件 | 用途 |
|---|---|
| `CokeAI-项目介绍.pptx` | PowerPoint / WPS / Keynote 打开，16:9，可直接放映或改 |
| `index.html` | 浏览器打开，方向键 / 空格翻页，适合快速浏览 |
| `../PRESENTATION.md` | GitHub 直接阅读的逐页文字版 |

## 打开 HTML

直接双击 `index.html` 即可，无需服务器、无外部请求（字体用系统自带）。

```bash
# 或在仓库根目录起一个静态服务
python3 -m http.server 8080
# 打开 http://localhost:8080/docs/presentation/
```

键盘：`→` / `↓` / 空格 / `PageDown` 下一页，`←` / `↑` / `PageUp` 上一页，`Home` / `End` 到首尾。
地址栏 `#3` 这样的 hash 可以直接定位到某一页。

## 导出 PDF

HTML 版本用浏览器打印即可：`Cmd/Ctrl + P`，纸张选横向、边距无、勾选背景图形，会按 16:9 每页一张输出。
PowerPoint 版本直接“另存为 PDF”。
